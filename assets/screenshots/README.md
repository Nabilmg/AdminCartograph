# Screenshots

Drop your real-data screenshots here so the README shows what the
visual actually does in your report. The README references these
filenames — when they exist, they replace the illustrative SVG
placeholders.

| Filename | What it should show |
|---|---|
| `01-hero.png` | Full-canvas Admin1 view: choropleth + bubbles + labels visible, value legend in a corner. Crop tightly around the visual (no Power BI chrome). |
| `02-format-pane.png` | Right-hand format pane open with the 14 numbered cards visible. Expand "1. Map setup" so the Country dropdown is open. |
| `03-three-layers.png` | Same data as the hero, but with the Pie / Column overlay enabled (donut, 2-3 measures) so all three layers stack on the map. |
| `04-drill.png` | After clicking an Admin1: title pill in the top-left, prev/next arrows beside it, focused state's Admin2 polygons coloured by data, dimmed neighbour states around the edges. |
| `05-custom-upload.png` | Country = Custom: the upload card on the canvas with the four field-mapping dropdowns populated after a file has been chosen. |
| `06-powerpoint.png` | A PowerPoint slide with the A5 PNG export inserted, to demonstrate the end-to-end output story. |

## How to take them on Power BI Desktop

1. Build a small report with one country bound to AdminCartograph.
2. Use **Win + Shift + S** (Windows) or **Cmd + Shift + 4** (macOS)
   to grab a clean rectangular crop of just the visual.
3. Save into this folder with the matching filename.

Once these files exist the README's "What it looks like" section
will pick them up automatically (Markdown image references already
point at the filenames above).
